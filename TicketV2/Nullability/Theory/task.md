## Відсутні значення

Наша реалізація методу `assigned` доволі прямолінійна: паніка для нерозпочатих і виконаних тікетів — далеко не ідеальне рішення.\
Ми можемо зробити краще за допомогою **типу `Option`**, який є в Rust.

## `Option`

`Option` — це тип Rust, що представляє **значення, яких може не бути** (nullable values).\
Це enum, оголошений у стандартній бібліотеці Rust:

```rust
enum Option<T> {
    Some(T),
    None,
}
```

`Option` виражає ідею, що значення може бути присутнім (`Some(T)`) або відсутнім (`None`).\
Крім того, він змушує вас **явно обробляти обидва випадки**. Якщо ви працюєте зі значенням, якого може не бути,
і забудете обробити випадок `None`, то отримаєте помилку компіляції.\
Це суттєве покращення порівняно з «неявною» можливістю відсутності значення (nullability) в інших мовах, де можна забути
перевірити значення на `null` і так спричинити помилку під час виконання.

## Визначення `Option`

У визначенні `Option` використано конструкцію Rust, якої ви ще не бачили: **tuple-like variants** (кортежоподібні варіанти).

### Tuple-like variants

`Option` має два варіанти: `Some(T)` і `None`.\
`Some` — це **tuple-like variant**: варіант, що містить **безіменні поля**.

Tuple-like variants часто використовують, коли потрібно зберігати лише одне поле, особливо якщо йдеться про
тип-«обгортку» на кшталт `Option`.

### Tuple-like structs

Таке буває не лише в enums — можна оголошувати й tuple-like structs:

```rust
struct Point(i32, i32);
```

До двох полів екземпляра `Point` можна звертатися за їхнім порядковим індексом:

```rust
let point = Point(3, 4);
let x = point.0;
let y = point.1;
```

### Кортежі

Дивно казати, що щось схоже на кортеж, коли ми ще не бачили самих кортежів!\
Кортежі — ще один приклад примітивного типу Rust.
Вони об'єднують фіксовану кількість значень (можливо, різних типів):

```rust
// Два значення одного типу
let first: (i32, i32) = (3, 4);
// Три значення різних типів
let second: (i32, u32, u8) = (-42, 3, 8);
```

Синтаксис простий: типи значень перелічують у круглих дужках через кому.
До полів кортежу звертаються через крапку та індекс поля:

```rust
assert_eq!(second.0, -42);
assert_eq!(second.1, 3);
assert_eq!(second.2, 8);
```

Кортежі — зручний спосіб згрупувати значення, коли не хочеться оголошувати для цього окремий struct.
