## Залежності

Пакет може залежати від інших пакетів — для цього їх перелічують у розділі `[dependencies]` його файлу `Cargo.toml`.\
Найпоширеніший спосіб задати залежність — указати її назву та версію:

```toml
[dependencies]
thiserror = "1"
```

Так ви додасте до свого пакета залежність `thiserror` з **мінімальною** версією `1.0.0`.
`thiserror` буде завантажено з [crates.io](https://crates.io) — офіційного реєстру пакетів Rust.
Коли ви запускаєте `cargo build`, `cargo` проходить кілька етапів:

- розв'язання залежностей (dependency resolution);
- завантаження залежностей;
- компіляція проєкту (вашого власного коду та залежностей).

Етап розв'язання залежностей пропускається, якщо в проєкті є файл `Cargo.lock`, а файли маніфестів не змінилися.
Після успішного розв'язання залежностей `cargo` автоматично генерує lock-файл, який містить
точні версії всіх залежностей, використаних у проєкті, і гарантує, що в різних збірках (наприклад, у CI)
завжди використовуються ті самі версії. Якщо над проєктом працює кілька розробників,
файл `Cargo.lock` варто закомітити в систему контролю версій.

Щоб оновити в `Cargo.lock` версії всіх залежностей до найновіших (сумісних), скористайтеся командою `cargo update`.

### Залежності за шляхом

Залежність також можна задати через **шлях** (path). Це зручно, коли ви працюєте з кількома локальними пакетами.

```toml
[dependencies]
my-library = { path = "../my-library" }
```

Шлях задається відносно файлу `Cargo.toml` пакета, який оголошує залежність.

### Інші джерела

Докладніше про те, звідки можна брати залежності і як задавати їх у файлі `Cargo.toml`, читайте
в [документації Cargo](https://doc.rust-lang.org/cargo/reference/specifying-dependencies.html).

## Залежності для розробки

Також можна задати залежності, потрібні лише під час розробки, — тобто ті, що завантажуються, лише коли ви
запускаєте `cargo test`.\
Їх записують у розділ `[dev-dependencies]` файлу `Cargo.toml`:

```toml
[dev-dependencies]
static_assertions = "1.1.0"
```

У цьому курсі ми вже використовували кілька таких залежностей, щоб скоротити тести.
