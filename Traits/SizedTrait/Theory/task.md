## `Sized`

Навіть після того як ми розібралися з deref coercion,
`&str` приховує більше, ніж здається на перший погляд.\
Зважаючи на наше попереднє [обговорення розміщення в пам'яті](../../../TicketV1/ReferencesInMemory/Theory/task.md),
було б логічно очікувати, що `&str` представлений у stack одним `usize` — pointer.
Проте це не так. Поруч із pointer `&str` зберігає певні **метадані**:
довжину slice (slice: зріз — вид на частину послідовності), на який він вказує. Повернімося до прикладу з
[одного з попередніх уроків](../../../Traits/StringSlices/Theory/task.md):

```rust
let mut s = String::with_capacity(5);
s.push_str("Hello");
// Створюємо з `String` reference на string slice,
// пропускаючи перший байт.
let slice: &str = &s[1..];
```

У пам'яті отримуємо таке:

```text
                    s                              slice
      +---------+--------+----------+      +---------+--------+
Stack | pointer | length | capacity |      | pointer | length |
      |    |    |   5    |    5     |      |    |    |   4    |
      +----|----+--------+----------+      +----|----+--------+
           |        s                           |  
           |                                    |
           v                                    | 
         +---+---+---+---+---+                  |
Heap:    | H | e | l | l | o |                  |
         +---+---+---+---+---+                  |
               ^                                |
               |                                |
               +--------------------------------+
```

Що ж тут відбувається?

## Dynamically sized types

`str` — це **dynamically sized type** (DST).\
DST — це тип, розмір якого невідомий під час компіляції. Щоразу, коли у вас є
reference (reference: посилання на значення) на DST, як-от `&str`, він мусить містити додаткову
інформацію про дані, на які вказує. Такий reference — це **fat pointer**.\
У випадку `&str` він зберігає довжину slice, на який вказує.
Інші приклади DST ми побачимо далі в курсі.

## Trait `Sized`

У стандартній бібліотеці Rust (`std`) визначено trait під назвою `Sized`.

```rust
pub trait Sized {
    // Це порожній trait: реалізовувати жодних методів не потрібно.
}
```

Тип є `Sized`, якщо його розмір відомий під час компіляції. Іншими словами, це не DST.

### Marker traits

`Sized` — ваш перший приклад **marker trait**.\
Marker trait — це trait, який не вимагає реалізації жодних методів. Він не визначає жодної поведінки.
Він лише **позначає** тип як такий, що має певні властивості.
Далі компілятор використовує цю позначку, щоб увімкнути певну поведінку чи оптимізації.

### Auto traits

Зокрема, `Sized` — це ще й **auto trait**.\
Вам не потрібно реалізовувати його явно: компілятор автоматично реалізує його за вас
на основі визначення типу.

### Приклади

Усі типи, які ми досі бачили, є `Sized`: `u32`, `String`, `bool` тощо.

`str`, як ми щойно побачили, не є `Sized`.\
А от `&str` — `Sized`! Ми знаємо його розмір під час компіляції: два `usize`, один для pointer
і один для довжини.
