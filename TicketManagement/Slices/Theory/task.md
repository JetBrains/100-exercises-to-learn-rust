## Зрізи

Повернімося до того, як `Vec` розміщується в пам'яті:

```rust
let mut numbers = Vec::with_capacity(3);
numbers.push(1);
numbers.push(2);
```

```text
      +---------+--------+----------+
Stack | pointer | length | capacity | 
      |  |      |   2    |    3     |
      +--|------+--------+----------+
         |
         |
         v
       +---+---+---+
Heap:  | 1 | 2 | ? |
       +---+---+---+
```

Ми вже зазначали, що `String` — це просто замаскований `Vec<u8>`.\
Ця схожість має підштовхнути вас до запитання: «А що для `Vec` є відповідником `&str`?»

## `&[T]`

`[T]` — це **зріз** (slice) неперервної послідовності елементів типу `T`.\
Найчастіше його використовують у запозиченій формі — `&[T]`.

Створити посилання на зріз із `Vec` можна кількома способами:

```rust
let numbers = vec![1, 2, 3];
// Через синтаксис індексування
let slice: &[i32] = &numbers[..];
// Через метод
let slice: &[i32] = numbers.as_slice();
// Або лише для частини елементів
let slice: &[i32] = &numbers[1..];
```

`Vec` реалізує трейт `Deref` із цільовим типом `[T]`, тож завдяки приведенню через розіменування (deref coercion)
методи зрізів можна викликати безпосередньо на `Vec`:

```rust
let numbers = vec![1, 2, 3];
// Яка несподіванка: `iter` — це не метод `Vec`!
// Це метод `&[T]`, але його можна викликати на `Vec`
// завдяки приведенню через розіменування (deref coercion).
let sum: i32 = numbers.iter().sum();
```

### Розміщення в пам'яті

`&[T]` — це **«товстий» вказівник** (fat pointer), як і `&str`.\
Він складається з вказівника на перший елемент зрізу та довжини зрізу.

Якщо у вас є `Vec` із трьома елементами:

```rust
let numbers = vec![1, 2, 3];
```

і ви створите посилання на зріз:

```rust
let slice: &[i32] = &numbers[1..];
```

то отримаєте ось таке розміщення в пам'яті:

```text
                  numbers                          slice
      +---------+--------+----------+      +---------+--------+
Stack | pointer | length | capacity |      | pointer | length |
      |    |    |   3    |    4     |      |    |    |   2    |
      +----|----+--------+----------+      +----|----+--------+
           |                                    |  
           |                                    |
           v                                    | 
         +---+---+---+---+                      |
Heap:    | 1 | 2 | 3 | ? |                      |
         +---+---+---+---+                      |
               ^                                |
               |                                |
               +--------------------------------+
```

### `&Vec<T>` проти `&[T]`

Коли потрібно передати у функцію незмінюване посилання на `Vec`, віддавайте перевагу `&[T]`, а не `&Vec<T>`.\
Тоді функція зможе приймати будь-який зріз, не обов'язково той, за яким стоїть `Vec`.

Наприклад, так можна передати лише частину елементів `Vec`.
Але можливості цим не обмежуються — можна передати й **зріз масиву**:

```rust
let array = [1, 2, 3];
let slice: &[i32] = &array;
```

Зрізи масивів і зрізи `Vec` мають один і той самий тип: це «товсті» вказівники на неперервну послідовність елементів.
У випадку масивів вказівник указує на стек, а не на купу, але для роботи зі зрізом
це не має значення.
