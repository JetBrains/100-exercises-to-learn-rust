## Асинхронний Rust
##
Потоки (threads) — не єдиний спосіб писати конкурентні програми на Rust.\
У цьому розділі ми розглянемо інший підхід — **асинхронне програмування**.

Зокрема, ви ознайомитеся з:

- ключовими словами `async`/`.await`, які дають змогу без зусиль писати асинхронний код;
- trait `Future` (trait: набір методів, які тип може реалізувати; аналог інтерфейсу), що представляє обчислення, які, можливо, ще не завершилися;
- `tokio` — найпопулярнішим runtime (середовищем, яке виконує асинхронний код) для запуску асинхронного коду;
- кооперативною природою асинхронної моделі Rust і тим, як вона впливає на ваш код.
